# SPORTLINE

Начална версия на дипломен онлайн магазин за спортни стоки с C#, ASP.NET Core MVC, Razor Views, Bootstrap, EF Core Code First и SQL Server.

## Етап 1

Налични са начална страница, прост каталог с търсене по име и подробности за размерите, цветовете и наличностите. Базата има 5 таблици и примерни данни за 6 продукта с 12 варианта.

Профили, роли, количка, поръчки, промоции и служебно управление са планирани за следващите етапи.

[Документация](docs/Etap-1.md) · [Word файл](docs/Etap-1-Documentation.docx)

## Стартиране

Необходими са Visual Studio 2026 с ASP.NET and web development, .NET 10 SDK и SQL Server LocalDB.

При първа подготовка създайте отделната локална инстанция:

```powershell
SqlLocalDB create SportlineStage1Basic -s
```

Изпълнете от папката на решението:

```powershell
dotnet restore SportStore.sln
dotnet run --project src/SportStore.Web -- --initialize-database
dotnet run --project src/SportStore.Web
```

Отворете `http://localhost:5158`. Във Visual Studio отворете `SportStore.sln` и стартирайте `SportStore.Web` след подготовката на базата.

Инициализаторът създава база `SportlineStage1Basic`, прилага миграцията и зарежда примерните данни. Повторното изпълнение не ги дублира. Нормалното стартиране не променя автоматично схемата.

## Подредба

- `Controllers` и `Views` обработват заявките и показват страниците.
- `Services` подготвя данните за каталога.
- `Entities` и `Data` описват обектите, връзките, миграцията и началните записи.
- `wwwroot` съдържа локалните стилове и изображения.

Началната схема е описана и в `database/initial-schema.sql`. SQL скриптът не съдържа примерните записи; за тях използвайте инициализатора.

Проверено е успешно компилиране и работа с реалната SQL Server база. Каталогът връща 6 продукта, търсенето и вариантите работят, а отрицателна наличност се отхвърля от базата. Автоматичните тестове се планират с разработването на следващите функции.

Кодът и документацията са публично достъпни за четене от дипломния консултант.
